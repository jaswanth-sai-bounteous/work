# Workout Tracker

A responsive React workout tracker built with Vite, React Router, and localStorage persistence.

## Features

- 3 workout days: Upper, Core, Legs
- Embedded YouTube exercise videos
- Mark exercises complete
- Completion counts saved in localStorage
- Progress page with progress bars
- Difficulty unlock after 3 completions on any day
- Reset progress button
- Streak counter

## Run It

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- All data is stored in the browser with localStorage.
- Difficulty adds `+5` to each exercise target per level.
